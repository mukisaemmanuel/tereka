# TEREKA V1 — AI-POWERED PERSONAL FINANCIAL INTELLIGENCE SYSTEM

Build a modern, production-quality web application called **Tereka**.

## 1. PRODUCT VISION

Tereka is an AI-powered personal financial intelligence system designed initially for users in East Africa.

The purpose of the application is to help users understand:

* Where their money comes from
* Where their money goes
* How much money they currently have
* Whether they are following their budgets
* Whether they are progressing toward financial goals
* How they can improve their financial decisions

Tereka is **not just an expense tracker**. The user experience should feel like a modern financial intelligence platform.

The central question Tereka should help answer is:

> "Where is my money coming from, where is it going, and am I financially okay?"

---

# 2. IMPORTANT V1 BOUNDARIES

For Version 1, DO NOT build:

* Real money transfers
* MTN MoMo API integrations
* Airtel Money API integrations
* Bank transfer integrations
* Currency exchange execution
* Wallet functionality that holds real customer money
* Lending
* Investment execution
* Cryptocurrency features

However, design the application architecture so that future financial integrations can be added without rebuilding the entire system.

Version 1 focuses on:

* Personal financial tracking
* Financial analysis
* Budgeting
* Savings goals
* AI-powered financial insights

# 16. SECURITY REQUIREMENTS

This is financial data.

Implement Row Level Security.

Every user must only access their own:

* Profile
* Accounts
* Categories
* Transactions
* Budgets
* Goals
* AI conversations
* AI messages

Never trust user IDs sent from the frontend.

Use the authenticated user identity.

Do not expose:

* Service role keys
* AI API keys
* Private credentials

Do not create insecure public database tables.

---

# 17. FINANCIAL CALCULATIONS

Create reusable financial calculation utilities.

Do not scatter financial calculation logic throughout React components.

Create reusable functions/services for calculations such as:

* Total balance
* Monthly income
* Monthly expenses
* Spending by category
* Budget progress
* Goal progress

Use proper TypeScript types.

Avoid using JavaScript floating-point arithmetic carelessly for money.

Design money handling so it can later support accurate financial calculations.
